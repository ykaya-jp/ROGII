## 要約 — test 3 wells の本質特徴 (= CV 設計の前提)

### F1. b_ANCC cluster は 2 種類 (= 11373 × 2、 11855 × 1)
- w0=11373, w2=11373 (= 同一 cluster)、 w1=11855 (= 別 cluster)
- train 67 cluster の中で **大きな b 側** (= p60-83)、 中央/小 cluster は test に居ない
- 含意: **fold val には 11373 + 11855 が必ず含まれていないと test 分布を rep しない**

### F2. typewell geology class 数は 2 modal (= 6 class × 1、 10 class × 2)
- w0=10, w2=10 (= train で p89、 マイナー、 OLMOS 系 28 wells の親族?)
- w1=6 (= train で p2、 majority class)
- 含意: typewell 構造が **異なる 2 群** が同時に val 必要

### F3. visible_ratio は 20-33% (= train p13-85 の中央域だが幅広)
- w0=27%, w1=20%, w2=33%
- w1 = 20% visible で 80% hidden = 予測難度最大
- 含意: val fold で visible_ratio 一定では w1 の難度を再現できない → **stratify 必要**

### F4. n_visible (絶対値) は 1442-2083 で散らばる (= p11, p25, p96)
- w0=1442 (= 短い側)、 w2=2083 (= 長い側 train でも extreme)
- 含意: visible_ratio だけでは捉えきれない、 **n_visible bin** も独立軸

### F5. GR signal は **w2 だけ extreme outlier** (= gr_ac10/50 p100、 gr_mean p2、 GR std p100)
- w2: gr_kurt p0 (= 最も尖ってない/flat)、 tail_100_gr_mean p1
- w0/w1: moderate
- 含意: val fold に **GR-extreme well を 1 件含める** ように設計しないと w2 の難度 rep 不能

### F6. tail dTVT 全部 +1 (= 末端上昇方向)
- train は -1/+1 が 50/50 split、 test 3 wells 全部 +1 (= 偶然か bias か不明)
- 含意: tail-direction sign-aware modeling は **fold-stratify するなら +1/-1 比を意識**

### F7. typewell_geology_n_labeled は test 全件 p6-8 (= train minority)
- w0=997, w1=1024, w2=997 (= train p10=1024)
- 含意: typewell labeled rows 少ない wells が test = train でも少ない群を val 化必要

### F8. typewell content-hash duplicate (= Edge Q 発見の 13 group) は test wells に対応するものを必ず特定して同一 fold に
- 既存 Edge Q 設計の重要性が test profile からも裏付け

## CV 設計示唆 — 構造原理が異なる 5 候補 (= 次ステップ)

|---|---|---|---|
| C1 | **pseudo-test fold** (= test 3 wells に kNN で最も近い train wells を val 固定) | kNN-based | F1-F7 全部間接的に rep (= 距離関数の重み次第) |
| C2 | **multi-axis stratified GroupKFold** (= visible_ratio × b_cluster × typewell_n_classes × tail_dir で層化) | bin stratification | F1+F2+F3+F6 を直接 strat |
